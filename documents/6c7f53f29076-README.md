# 軟體與伺服器銷售證據簡報

本專案將成交文件、郵件、週報與官網快照整理成可追溯的簡報。原始文件、`_md/` 與既有 Grok 分析保留不改；成交紀錄不能替代未成交報價的分母。

在專案根目錄，使用已安裝的 Python 環境依序執行：

```sh
python3 analysis/ledger.py && python3 analysis/emails.py && python3 analysis/stats.py && python3 analysis/quotes.py && python3 analysis/weekly_series.py && python3 deck/build_deck.py && python3 -m pytest -q
python3 deck/build_deck.py --spec deck/spec_interview.json --out deck/out/interview && python3 deck/dump_text.py --pptx deck/out/interview/vendor_deck.pptx --text deck/out/interview/deck_text.txt
```

ERP 報價匯出放在 `analysis/inputs/quotes_export.csv` 或 `quotes_export.xlsx`，並在 `analysis/inputs/quotes_columns.json` 設定實際欄名、日期格式、狀態值與工作表。沒有匯出時，簡報顯示待補資料，不估算報價命中率。產業分類改 `analysis/industry_map.csv`；機型系列分類改 `analysis/reference/series_map.json`，兩者依規則順序採第一個符合項目。

簡報規格在 `deck/spec.json`。`deck/out/vendor_deck.pptx` 是交付簡報；每頁備註記錄 `spec id | claim_level | part`。內容過密時產生續頁，保留相同 spec ID 與頁尾的本題頁次。`deck/out/resolved.json` 記錄引用值與來源標籤，包括圖表輸入及流程節點。

文字與最終 QA：

```sh
python3 deck/build_deck.py && python3 deck/dump_text.py > /dev/null && python3 -m pytest -q
```

單獨執行 `python3 deck/dump_text.py` 會輸出逐頁文字，並同步寫入 `deck/out/deck_text.txt`。需有本機 `_md/` 才能執行全部真實文件測試；缺少時該類測試會跳過。

PDF 供目視檢查；LibreOffice 不存在或轉檔失敗時略過，不影響測試結果：

```sh
# PDF 只能在一般 shell 轉；Codex 沙盒內執行 soffice 會 SIGABRT（macOS 跳當機視窗）。
if [ -x /opt/homebrew/bin/soffice ]; then
  /opt/homebrew/bin/soffice --headless --convert-to pdf --outdir deck/out deck/out/vendor_deck.pptx || echo '略過 PDF：LibreOffice 轉檔失敗'
else
  echo '略過 PDF：未安裝 LibreOffice'
fi
```

| 來源標籤 | 證據範圍 |
| --- | --- |
| 週報 | 目標與入帳期間資料，重疊週報不可相加 |
| 文件 | SO、PO、郵件等本櫃文件及衍生統計 |
| 官網 | 官網快照，附網址與擷取日期 |
| 待驗證 | 尚需向負責人確認的組織資料 |
| 產品知識 | 產品背景知識，不等同本櫃成交證據 |
| 內部流程 | 使用者提供的流程經驗；節點下方數字另以文件證據標示 |
